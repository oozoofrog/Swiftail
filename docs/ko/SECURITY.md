# 보안 정책

## 지원 버전

최신 `0.x` 릴리스와 `main` 브랜치에 보안 수정 사항을 적용합니다. 이전 릴리스에는 수정 사항을 적용하지 않습니다.

## 취약점 보고

저장소의 **Security** 탭을 열고 **Report a vulnerability**를 선택해 GitHub에서 비공개로 보고하세요. 의심되는 취약점에 대해 공개 이슈, 풀 리퀘스트, 토론을 열지 마세요.

실제 키, 인증 키, 노드 키, tailnet 이름, 기기 이름 또는 이런 정보가 들어 있는 로그를 보고서에 넣지 마세요. `tail0001`, `100.64.0.1` 같은 예시 값을 사용하세요.

이 정책은 Swiftail 코드에 적용됩니다. Tailscale 제어 서버나 Go 클라이언트의 문제는 Tailscale에 보고하세요. [README의 보안 항목](../../README.md#security)이나 [모듈 계약](../contracts/)에 기록된 제한 사항만으로는 취약점임을 입증하기에 충분하지 않습니다.

메인테이너 한 명이 가능한 범위에서 보고를 처리하며 응답 기한은 보장하지 않습니다. 보안 수정 사항은 PATCH 릴리스로 배포하며, 필요한 경우 보안 권고문을 함께 게시합니다.
